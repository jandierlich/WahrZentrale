# QRWahr

Unabhängiger QR-Code-Scanner innerhalb der WahrZentrale.

- Kamera-Scan per @zxing/library (Apache-2.0), rein lokal im Browser
- Zeigt den erkannten Inhalt nur an – keine automatische Weiterleitung
- Optionaler Button "Extern öffnen" öffnet den Link erst nach explizitem Tippen
- Kein eigener Server, keine Speicherung von Scan-Ergebnissen
- Komplett eigenständig: eigenes Impressum, eigene Datenschutzerklärung, eigener Service Worker
